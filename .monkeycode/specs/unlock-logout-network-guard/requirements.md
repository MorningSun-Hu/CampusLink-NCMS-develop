# Requirements Document

# Introduction

补齐三类教室管控能力：学生机超级密码解锁后教师端同步恢复解锁前模式并保持使用会话；教师端提供退出登录以切换用户；授课模式下甄别真实断网与故意阻断后立即锁屏，网络恢复后向教师端推送异常告警。

涉及范围：`student-agent`、`teacher-server`、`teacher-web`。

## Glossary

- **解锁前模式**：设备进入锁定前保存在 `mode_before_lock` 中的模式，取值 `open`、`teaching` 或 `exam`。
- **超级密码解锁**：学生在锁屏或签到界面输入教师超级密码后退出锁定界面。
- **教师远程解锁**：教师在教师端对设备执行解锁。
- **使用会话**：`device_usage_records` 中 `end_time` 为空的进行中记录。
- **退出登录**：教师端清除当前登录态并回到登录页。
- **物理链路断开**：本机网卡操作状态为断开，例如网线拔出。
- **相邻学生机问询**：向同一教室局域网内其他学生机询问教师机是否可达。
- **教师机不可达**：本机无法与教师机建立或维持管理连接。
- **故意阻断**：本机物理链路正常，相邻学生机报告教师机可达，本机教师机不可达。
- **网络异常锁屏**：授课模式下因物理链路断开或故意阻断而进入锁定界面。
- **网络恢复**：物理链路恢复且本机重新连上教师机。

## Requirements

### Requirement 1: 超级密码解锁后恢复解锁前模式

**User Story:** AS 教师, I want 学生用超级密码解锁后教师端显示解锁前模式, so that 进行中的上课状态与使用记录一致。

#### Acceptance Criteria

1. WHEN 设备处于锁定且解锁前模式有效，并且学生完成超级密码解锁, 学生机 SHALL 进入该解锁前模式对应的界面与策略。
2. WHEN 学生完成超级密码解锁, 教师端该设备的当前模式 SHALL 更新为解锁前模式。
3. WHEN 学生完成超级密码解锁且该设备存在使用会话, 系统 SHALL 保持该使用会话的结束时间为空。
4. WHEN 教师执行教师远程解锁, 教师端与学生机 SHALL 进入该设备的解锁前模式。

### Requirement 2: 教师端退出登录

**User Story:** AS 教师, I want 点退出后换另一个账号登录, so that 同一台教师机可以切换用户。

#### Acceptance Criteria

1. WHILE 教师已登录, 教师端 SHALL 在页眉用户区域展示「退出」按钮。
2. WHEN 教师点击「退出」, 教师端 SHALL 清除本地登录凭证并进入登录页。
3. WHEN 教师在登录页使用另一账号登录成功, 教师端 SHALL 以该账号的身份与权限进入系统。

### Requirement 3: 授课模式真实断网立即锁定

**User Story:** AS 教师, I want 学生机真断网时立刻锁屏, so that 拔网线无法继续使用授课桌面。

#### Acceptance Criteria

1. WHILE 设备处于授课模式, 学生机 SHALL 监视本机物理链路状态。
2. WHEN 设备处于授课模式且发生物理链路断开, 学生机 SHALL 在 3 秒内进入锁定界面。
3. WHEN 设备因物理链路断开进入锁定, 学生机 SHALL 将本次原因记录为物理链路断开。
4. WHILE 设备处于授课模式且教师机不可达，并且相邻学生机问询结果表明其他学生机同样教师机不可达, 学生机 SHALL 保持授课模式界面与策略。

### Requirement 4: 授课模式故意阻断立即锁定

**User Story:** AS 教师, I want 学生用防火墙挡住教师机时立刻锁屏, so that 伪装断网无法继续上课桌面。

#### Acceptance Criteria

1. WHILE 设备处于授课模式且物理链路正常且教师机不可达, 学生机 SHALL 向相邻学生机问询教师机是否可达。
2. WHEN 相邻学生机问询结果表明至少一台相邻学生机教师机可达, 学生机 SHALL 在 3 秒内进入锁定界面。
3. WHEN 设备因故意阻断进入锁定, 学生机 SHALL 将本次原因记录为故意阻断。
4. IF 相邻学生机问询在 2 秒内无应答且物理链路正常, 学生机 SHALL 再重试 1 次问询后再按教师机不可达处理。

### Requirement 5: 网络恢复后告警并恢复授课

**User Story:** AS 教师, I want 学生机网络恢复后马上看到异常告警, so that 我知道这台机器刚断网或被阻断。

#### Acceptance Criteria

1. WHEN 设备处于网络异常锁屏并且发生网络恢复, 学生机 SHALL 进入解锁前模式（授课模式）。
2. WHEN 设备发生网络恢复且本次锁定原因为物理链路断开, 教师端 SHALL 新增一条状态为异常的告警，条目为物理链路断开。
3. WHEN 设备发生网络恢复且本次锁定原因为故意阻断, 教师端 SHALL 新增一条状态为异常的告警，条目为故意阻断。
4. WHEN 上述告警写入, 教师端检查告警列表 SHALL 能立即看到该条告警。
5. WHEN 设备发生网络恢复且该设备存在使用会话, 系统 SHALL 保持该使用会话的结束时间为空。

## 已确认决策

1. 超级密码解锁与教师远程解锁都恢复 `mode_before_lock`，进行中的使用会话保持未结束。
2. 教师端退出只清本地登录态并回登录页。
3. 授课模式锁定只针对物理链路断开与故意阻断；教师机死机且相邻学生机同样连不上教师机时保持授课。
4. 网络恢复后恢复授课并写告警，告警走现有检查告警列表。
