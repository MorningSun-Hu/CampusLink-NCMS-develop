**前端基础设施**: axios 共享实例 (`api/http.ts`)、自动 Bearer Token 注入、401 死循环防护

### 学生端 Agent (3 进程 x 18 模块)

**agent-core**: 信息采集、设备注册、配置持久化 (config.enc AES256)、WebSocket 30s 心跳、Binary 消息加解密、签到/检查、硬件采集 (sysinfo + WMIC 外设)、模式切换联动锁屏、UDP 广播发现、指纹双向校验、进程守护策略同步、campus-guard 存活监控、锁屏进程退出检测

**campus-guard**: 双进程守护 (agent-core + campus-lock), 异常退出自动拉起 (上限 10 次)

**campus-lock**: 全屏 eframe GUI、超级密码解锁、失败计数限流、WH_KEYBOARD_LL 键盘钩子 (Win/Alt+Tab/Alt+F4/Ctrl+Esc 屏蔽)、IME 修复

### 安全通信

- JWT: HS256, 8h 有效期, admin_users 表, bcrypt (cost 4)
- WebSocket 加密: AES256-GCM, 12 字节 nonce + ciphertext, Message::Binary, session_key 协商
- 本地配置: config.enc AES256-GCM, PBKDF2 密钥派生

### 部署运维

- `install.bat`: 管理员检测 + 一键全装 (Service + 防火墙 + 计划任务)
- `uninstall.bat`: 统一卸载 (保留数据)
- `teacher-server/install-service.bat`: sc create (开机自启 + 崩溃重启)
- `teacher-server/install-firewall.bat`: netsh TCP 8080 放行
- `student-agent/install-autostart.bat`: schtasks onlogon
- `teacher-server/generate-cert.bat`: HTTPS 自签名证书 (OpenSSL/PowerShell)
- 配置路径 exe-relative 自动解析 (支持 Windows Service 环境)
- `docs/deployment-guide.md`: 拓扑/安装/运维/故障排查/安全
