# CampusLink-NCMS 模块开发路线

## 第一阶段

- 完成教师端服务基础工程
- 建立数据库迁移与配置加载
- 建立教师端 Web 基础布局与路由
- 建立 Protobuf 协议文件

## 第二阶段

- 完成学生注册与设备管理
- 完成模式控制中心
- 完成实时监控与心跳链路
- 完成签到与检查流程

## 第三阶段

- 完成硬件快照与变更告警
- 完成自定义进程守护策略
- 完成网络认证管理
- 完成日志中心与审计能力

## 第四阶段

- 完成学生端锁定与安全能力
- 完成部署脚本与安装包
- 完成联调、压测与验收

## 开发优先级

### P0

- 工程初始化
- 数据库与协议
- 注册、心跳、在线状态
- 模式控制基础链路

### P1

- 学生与设备管理
- 签到与检查流程
- 座位图监控
- 日志中心

### P2

- 硬件变更告警
- 自定义进程守护
- 网络认证
- 超级密码与强制解锁

### P3

- 打包安装
- 升级脚本
- 性能压测与灰度方案

## 推荐开发顺序

1. 完成 `teacher-server` 基础工程、数据库迁移、协议定义
2. 完成 `teacher-web` 的基础布局、登录态、设备列表与监控总览
3. 完成 `student-agent` 的注册、心跳、模式接收与签到链路
4. 扩展检查、告警、日志、网络认证、锁屏能力
5. 完成部署脚本、安装包、压测与验收
