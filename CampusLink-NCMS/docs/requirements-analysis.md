# CampusLink-NCMS 需求分析

## 角色定义

### 教师端管理员

- 维护系统配置与全局策略
- 管理学生、设备、网络认证账号、超级密码
- 查看审计日志与告警记录

### 任课教师

- 管理课堂模式
- 发起签到与检查
- 监控学生机状态
- 处理远程控制与异常告警

### 学生端设备

- 注册到教师端
- 接收模式控制指令
- 执行签到、检查、硬件上报、认证登录

## 功能域拆分

### 1. 教师端服务

- 系统配置加载与教师机指纹生成
- 学生机发现、注册、白名单管理
- 学生与座位信息管理
- 模式控制中心
- 实时状态监控
- 签到与检查流程管理
- 硬件与守护进程告警
- 网络认证管理
- 日志与审计中心

### 2. 教师端 Web 界面

- 总览仪表盘
- 学生与设备管理页
- 座位图与监控页
- 模式控制页
- 签到检查页
- 告警与日志页
- 系统配置页

### 3. 学生端 Agent

- 本地服务与双进程守护
- 教师端发现与注册
- 状态控制执行
- 登录签到
- 检查与硬件采集
- 网络认证
- 锁屏与应急解锁
- 本地加密存储

## 非功能要求

- 支持 100+ 学生机并发
- 教师端服务 Native 部署
- 学生端 Windows Service 自启动
- 通信采用 WebSocket + Protobuf + AES256-GCM
- 本地数据支持 SQLCipher 加密
