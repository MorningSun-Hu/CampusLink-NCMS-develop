# CampusLink-NCMS 开发任务拆解

## 一、功能需求分析

### 1. 核心业务目标

- 教师端统一管理网络教室、学生机、课堂模式与运行策略
- 学生端稳定接入教师端，持续执行注册、签到、检查、监控与安全控制
- 平台提供审计、告警、网络认证、应急解锁等运维能力

### 2. 角色与职责

#### 教师端管理员

- 管理系统配置、白名单、网络账号、超级密码、审计日志

#### 任课教师

- 管理课堂模式、签到检查、实时监控、远程操作、异常处理

#### 学生端设备

- 执行注册认证、状态上报、签到检查、模式切换、网络认证、锁屏控制

### 3. 业务模块

- 平台基础设施
- 教师端服务
- 教师端 Web 控制台
- 学生端 Agent
- 通信协议与安全体系
- 部署、联调与验收

## 二、开发任务分解

## 阶段 A：平台基础设施

### A1. 工程初始化

- 建立 Rust workspace 与教师端服务工程
- 建立教师端 Web 工程结构
- 建立学生端多进程 workspace
- 建立共享配置、日志、错误码规范

### A2. 配置与环境体系

- 设计 `config.toml` 结构
- 实现开发环境 SQLite 配置
- 预留生产环境 PostgreSQL 配置
- 约定日志目录、数据目录、备份目录

### A3. 数据库与迁移

- 设计核心表结构
- 建立 SQLx migration
- 设计初始化种子数据
- 设计数据库访问层与仓储接口

### A4. 通信协议

- 定义注册、心跳、模式切换、签到、检查、告警、日志协议
- 建立 Protobuf 文件与生成脚本
- 约定消息包头、版本号、错误码
- 设计 AES256-GCM 密钥交换与消息加密流程

## 阶段 B：教师端服务

### B1. 服务启动与基础中间件

- 配置加载
- 教师机指纹生成
- Axum 路由与中间件
- 统一日志与异常处理

### B2. 学生机注册管理

- UDP 广播发现接入策略
- 注册认证接口
- 白名单校验
- 批量导入设备能力

### B3. 学生与座位管理

- 学生信息 CRUD
- Excel 导入导出
- 座位信息维护
- 学生账号密码加密存储

### B4. 模式控制中心

- 开放模式
- 授课模式
- 条件开放模式
- 考试模式
- 锁定模式
- 热切换与定时切换

### B5. 实时监控中心

- 在线状态监控
- 心跳接收与离线判定
- 座位图状态聚合
- 远程操作指令下发

### B6. 签到与检查管理

- 学生签到流程
- 拍照上传接口
- 卫生检查、键盘检查、鼠标检查
- 维修工单记录
- 检查日志导出

### B7. 硬件与进程监控

- 硬件摘要接收与存档
- 硬件变更对比与告警
- 自定义进程守护策略下发
- PROCESS_ALERT 处理流程

### B8. 网络认证与超级密码

- 外网认证账号管理
- 自动登录与自动注销策略
- 超级密码修改
- 强制解锁与审计留痕

### B9. 日志与审计中心

- 注册日志
- 签到日志
- 检查日志
- 锁定日志
- 进程告警日志
- 操作审计查询与导出

## 阶段 C：教师端 Web 控制台

### C1. 前端基础框架

- 路由设计
- Pinia 状态管理
- Axios API 封装
- Element Plus 布局体系

### C2. 页面与交互

- 仪表盘
- 学生与设备管理页
- 座位图与实时监控页
- 模式控制页
- 签到检查页
- 告警日志页
- 系统配置页

### C3. 实时能力接入

- WebSocket 连接管理
- 实时状态刷新
- 告警弹窗与消息通知
- 模式切换结果反馈

## 阶段 D：学生端 Agent

### D1. 主进程 `agent-core`

- 启动流程与本地配置加载
- 教师机发现与注册
- 心跳与消息收发
- 签到、检查、认证、硬件采集
- 本地加密缓存

### D2. 守护进程 `campus-guard`

- 监控主进程存活状态
- 异常退出自动拉起
- 异常计数与日志上报

### D3. 锁屏进程 `campus-lock`

- 全屏锁定界面
- 超级密码解锁流程
- 快捷键限制策略

### D4. 双进程守护机制

- 主进程监控守护进程
- 守护进程监控主进程
- 自愈拉起策略
- 防误杀日志记录

### D5. 自定义进程守护

- 拉取教师端策略
- 按周期扫描目标进程
- 自动拉起受控进程
- 异常阈值触发告警

## 阶段 E：联调、部署与验收

### E1. 联调

- 教师端服务与 Web 联调
- 教师端与学生端协议联调
- 模式切换与锁屏联调
- 签到、检查、告警链路联调

### E2. 部署与安装

- 教师端 Native 发布目录
- 学生端 Windows Service 安装脚本
- 升级策略与备份恢复脚本

### E3. 测试与验收

- 单元测试
- 集成测试
- 100+ 设备并发压测
- 安全与稳定性验证

## 三、里程碑建议

### M1. 可启动骨架

- 教师端服务可启动
- 教师端 Web 可访问
- 学生端三个进程可独立启动
- Protobuf 协议可生成

### M2. 最小业务闭环

- 学生机完成注册
- 教师端可看到在线状态
- 教师端可切换课堂模式
- 学生端可执行签到

### M3. 课堂管理闭环

- 完成检查流程
- 完成座位图监控
- 完成告警上报
- 完成日志查询

### M4. 企业级能力闭环

- 完成网络认证
- 完成双进程守护
- 完成锁屏与应急解锁
- 完成压测与部署方案

## 四、优先级建议

### P0

- 工程初始化
- 数据库与协议
- 注册、心跳、在线状态
- 模式控制基础链路

### P1

- 学生与设备管理
- 签到与检查流程
- 座位图监控
- 日志中心

### P2

- 硬件变更告警
- 自定义进程守护
- 网络认证
- 超级密码与强制解锁

### P3

- 打包安装
- 升级脚本
- 性能压测与灰度方案

## 五、推荐实施顺序

1. 先完成 `teacher-server` 基础工程、数据库迁移、协议定义
2. 再完成 `teacher-web` 的基础布局、登录态、设备列表与监控总览
3. 然后完成 `student-agent` 的注册、心跳、模式接收与签到链路
4. 在最小闭环跑通后扩展检查、告警、日志、网络认证、锁屏能力
5. 最后完成部署脚本、安装包、压测与验收
